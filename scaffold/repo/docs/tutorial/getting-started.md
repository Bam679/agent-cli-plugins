# Getting started with __BIN__

In this tutorial you install `__BIN__`, read some of your __TITLE__ data with it, and then let it make one change in a container that exists only for this exercise. It takes about ten minutes. You need a terminal and __PLATFORMS__.

__TUTORIAL__

## What you have done

You installed `__BIN__` and read data with it. You saw that it refuses to write until a policy allows it, previewed a change with `--dry-run`, and applied it with `--confirm`.
